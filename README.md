# 브이리뷰 변환기

스마트스토어 리뷰 엑셀 → 브이리뷰 이관 파일 자동 변환 프로그램

## 사용 방법

1. `브이리뷰_스마트스토어_연동작업.xlsx` 선택
2. 스마트스토어에서 다운받은 리뷰 엑셀 선택
3. 날짜 확인 (자동 입력됨)
4. **브이리뷰 이관 파일 생성** 버튼 클릭
5. 저장 위치 선택 → 완료!

## EXE 빌드 방법

1. 이 저장소를 GitHub에 올리기
2. Actions 탭 → **Build EXE** → **Run workflow**
3. 완료 후 Artifacts에서 `브이리뷰_변환기.exe` 다운로드
